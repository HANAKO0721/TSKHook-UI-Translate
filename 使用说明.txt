TSKHook UI v0.1.0 — 繁体中文 UI 汉化扩展
适用：DMM Windows 版《Twinkle Star Knights》（闪耀星骑士）
前置：已安装并正常运行 TSKHook v1.1.6
更新日期：2026-09-11

本文使用简体中文。插件在游戏内仍输出繁体中文，并沿用现有译名。


一、这是什么

TSKHook UI 是独立的界面汉化扩展，以 TSKHook.UI.dll 加载。
原 TSKHook.dll 继续负责剧情汉化；本扩展补充菜单、任务、角色与装备资料、
商店、抽卡详情、游戏说明网页及部分图片文字，并修复已确认的界面生命周期问题。

本版随附：
  · 11,589 条 UI 词条；
  · 1,194 条网页词条；
  · 121 条图片规则；
  · 127 张人工 PNG。

本包需要原 TSKHook 的运行环境，不含游戏本体、完整 BepInEx 或原剧情字库。
上游项目：https://github.com/TSKModding/TSKHook


二、安装与更新

1. 确认基础版
   如果游戏已正常使用 TSKHook v1.1.6，可直接继续。
   如果尚未安装，请先按照上游说明安装并确认原剧情汉化能正常运行。

2. 完全关闭游戏
   确认 twinkle_starknightsX 已完全关闭后再复制文件。

3. 复制并替换
   将包内 TSKHook.UI.dll 和 TSKHook.UI 文件夹复制到游戏的 BepInEx/plugins/ 下，合并同名文件夹并替换本扩展的同名文件。

4. 启动游戏
   正常启动游戏，在 BepInEx/LogOutput.log 中确认出现：
   Loading [TSKHook UI 0.3.4]

请保留原 TSKHook.dll、font 字体目录、共用 config.json、已有缓存及
workspace.json 词表链接；不修改游戏 exe、GameAssembly.dll 或其他游戏源文件，
也不会自动添加在线翻译配置。


更换 DLL 后必须完全重启游戏。F9 不能加载新的 DLL。


三、哪些内容会保留原文

以下内容按本版设定保留原文：

  1. 图鉴中的“装备图鉴”主入口。
  2. 出击中的“合同演习”和“种族交流会”主入口。
  3. 星骑士中的“装备强化”主入口。
  4. 抽卡界面的卡池宣传底图，包括图片内嵌文案。
  5. 标题页及主页公告的正文、左侧文章标题、公告页签和文章子页。

前 3 项只保留主入口的原图，其子界面继续汉化。
主页“公告”按钮继续汉化；游戏说明和抽卡详情网页仍使用繁体译文。
这些保留原文的内容不属于漏译。


四、快捷键

F9   重载词表、图片规则、PNG 和扩展配置，刷新当前界面。
F4   采集当前已加载 UI 的原文、字体样式和图片信息。
F11  临时开关汉化；关闭时恢复原文和原图，不保存开关状态。
F1   由原 TSKHook 重读其基础配置。

只修改词表或图片时可用 F9；更新插件 DLL 后必须重启游戏。


五、配置文件在哪里

原剧情插件和 UI 扩展共同使用：
  游戏根目录/BepInEx/plugins/config.json

原有 speed、fps、translation、width、height、zoom 及其数值应保留。
不要用其他项目的配置模板或下面的片段替换整份现有文件。

使用包内离线词表和人工图片，不需要配置在线 API。
本安装器不创建或覆盖 config.json，也不会重新添加已移除的 ImageTranslation。

词表与配置的位置是两回事：
  · 独立安装：使用 BepInEx/plugins/TSKHook.UI/ 中的词表与图片。
  · 已有项目链接：若安装目录中存在有效的 workspace.json，
    则使用链接到的开发项目数据。启动日志出现
    UI dictionaries linked to project:
    表示正在使用项目词表。

即使链接到开发项目，共用配置仍读取游戏目录下的 config.json。
本发布包不附带 workspace.json，也不改变已有链接。


六、可选：文字自动补译

在线补译用于当前可见、尚未被离线词表和已有缓存覆盖的界面文字。
请求在后台处理，成功结果写入本地缓存；目标语言固定为繁体中文。

在现有 config.json 最外层添加或修改 OnlineTranslation。
下面是需要合并的结构片段，不是完整配置文件：

{
  "OnlineTranslation": {
    "Enabled": false,
    "url": "https://your-api.example/v1/responses",
    "ApiKey": "填写自己的 API 密钥",
    "Model": "填写服务支持的文字模型"
  }
}

如果已有 OnlineTranslation，只修改其中需要调整的字段，不要添加第二个同名块。
填好服务信息后，可按需将 Enabled 改为 true；保存后按 F9 生效。
示例地址、密钥和模型名均为占位内容，不能直接用于请求。

常用字段：
  Enabled     true 开启新请求；false 关闭新请求，继续使用离线词表和缓存。
  url         支持 Responses 接口的服务地址；字段名为小写 url。
  ApiKey      自己的服务密钥。
  Model       服务支持的文字模型名称。
  TimeoutSeconds              单次请求超时，默认 30 秒。
  MinimumIntervalMilliseconds 请求最小间隔，默认 1000 毫秒。
  MaximumRequestsPerSession   当前加载周期的请求上限，默认 800。
  FailureBackoffSeconds       失败后的初始暂停时间，默认 60 秒。

可使用服务的 /v1 基础地址或完整 /v1/responses 地址。
插件实际发送 Responses 请求；服务必须支持这一接口和所填写的模型。
API 地址不要填入网页聊天界面的地址。

离线词表优先于在线缓存。姓名、术语、数字、换行和富文本格式按现有规则保留。
玩家自行输入的名称、好友昵称和留言等内容保持原文。

未收录文本在请求完成前保留原文。遇到超时、HTTP 429 等错误时，
插件会暂停重试，已有离线汉化继续可用。


七、自己修改译文与图片

文字修改：
  1. 确认当前生效的数据目录。
  2. 按内容类别打开对应的 *-translations.json。
  3. 保留左侧日文原文键，只修改右侧繁体译文。
  4. 保留数字、\n 换行、富文本标签和 {0} 等占位符。
  5. 以 UTF-8 保存，回到游戏按 F9，重新打开相关界面检查。

简单格式示例：
{
  "日文原文": "对应的繁体译文"
}

不要把示例文本直接加入正式词表。包含换行的 JSON 字符串使用 \n，
不能在引号内部直接插入未转义的换行；条目之间的逗号也需要保留。

主要文件：
  ui-translations.json         通用界面词表
  completion-translations.json 补充短句与数值模板
  web-translations.json        游戏说明与抽卡详情等网页词表
  其他 *-translations.json     角色、装备、任务、商店等分类词表
  offline-dictionary.json      合并词典快照
  sprite-labels.json           图片替换及文字覆盖规则
  sprites/                    人工 PNG

修改图片时，应沿用对应资源的画布尺寸、透明区域和文字样式。
保存 PNG 后按 F9。只增加图片文件而没有对应规则，不会自动替换任意游戏资源。

F4 可采集已加载界面的文字和图片信息，采集位置以控制台输出为准。

九、常见问题与排错

1. 安装器提示先安装原 TSKHook
   检查 GamePath 是否指向实际游戏根目录，以及
   BepInEx/plugins/TSKHook.dll 是否存在。
   新安装请先完成基础版安装。

2. 安装器提示关闭游戏
   完全退出 twinkle_starknightsX 后再运行安装器。

3. 更新后没有效果
   更换 DLL 后重启游戏，并确认日志出现 Loading [TSKHook UI 0.3.4]。
   只修改词表时按 F9；如果已有 workspace.json，确认修改的是链接中的数据。

4. 仍有日文
   先核对第三节的保留原文范围。其他未收录内容在没有可用在线译文时会保留原文。
   可使用 F4 采集该界面，再补充离线词条。

5. API 返回 404、403、429 或超时
   检查服务地址、访问权限、额度，以及服务是否支持 Responses 和所填模型。
   插件会保留已有译文并暂停重试；修正配置后按 F9。

6. 出现 NullReferenceException 或切页异常
   记录发生时间、所在界面、切换顺序及是否按过 F9/F11。
   在再次启动游戏前保存下面两份日志：

   游戏根目录/BepInEx/LogOutput.log
   游戏根目录/BepInEx/plugins/TSKHook.UI/unity-exceptions.log

   Unity 例外文件每次启动会重置，一般日志也可能覆盖。
   部分 Interop 错误只写入 LogOutput.log，因此不能只看例外文件是否为空。
   游戏原有的部分 Warning 仍可能存在，应按具体内容判断。

7. 需要临时关闭汉化
   游戏内按 F11，再按一次可恢复。
   如果需要在启动前临时停用 UI 扩展，关闭游戏后将 TSKHook.UI.dll
   移出 plugins 目录；保留原 TSKHook.dll、共用配置和 UI 数据文件。


十、已知限制

  · 本版验证针对当前可进入的既有汉化页型，不代表全部数据实例及所有状态。
    期间锁定、特定角色和培养状态、未触发的战斗状态，以及部分付费、抽取、
    消耗材料或保存后的结果，尚未全部实机覆盖。
  · 礼物历史错图修补已通过代码测试，但原记录已超出可查看日期，
    同一笔记录的修复后实机结果尚未取得。
  · 少数新增敌人名采用暂定音译，尚未取得中文 Wiki 的固定译名。
  · 繁体字形使用现有 Noto 字库，以原版字号、粗细、斜体、描边与布局为基准。
    图片内嵌字的确切字体家族尚未全部确认。
  · 原剧情插件首次下载未缓存章节时的同步等待行为保持原样。
