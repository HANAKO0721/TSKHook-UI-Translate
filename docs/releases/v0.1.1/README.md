# TSKHook UI v0.3.7 繁體漢化擴充

適用於已安裝 TSKHook v1.1.6 的 DMM Windows 版《Twinkle Star Knights》。本版補齊優咪《爆裂》、狛里、新活動與商店的已取得文字和圖片，修正字型還原、戰鬥名字級、設定示例、飾品標題、素材數量及側章圖集替換。沿用既有繁體譯名，保留原劇情插件、共用設定與遊戲源檔。

## 本版變更

- 新增 99 條繁體詞條，涵蓋兩名新角色、四種 EX、完整簡介、專用裝備、活動、商品與禮包明細、道具及設定說明，以及神族交流會格里科恩初級；五處既有「九浄」統一為「九淨」。
- 新增 19 張 PNG：表情／重設 15 張、活動 3 張、H 故事角標 1 張；另重製 1 張既有側章圖集。活動名稱採「九淨家的新人女僕報到！～天ヶ崎優咪的新人培訓～」。
- 分頁文字保留原材質的描邊、字面膨脹與選取色；UGUI 切回原文時還原原字型。菲歐娜及梨緒的戰鬥姓名恢復原 24pt，保留文字框、斜體、對齊與行距。
- 設定文字速度示例在動畫開始前翻譯全文，F11 切換同步顯示長度上限，保留逐字動畫及原設定。種族交流會期間文字的 2023 初始化占位已修正。
- 飾品橙色欄以固定「装飾品：」前綴與已知完整名稱組合為繁體；道具數量格式沿用已知物品名，保留數字與 `<size=70%>×</size>` 等標記。
- 側章單頁圖集由 658×1792 更新為 670×1790，已按新尺寸重製。手動 Spine 替換圖尺寸失配時回退原圖並記一次 Warning，F9 重載可重試，避免入口消失與 F4 採集中斷。
- 「基本」「特殊」四張表情圖保持原圖；沿用既有角色固有狀態詞條及首次排版／繪製前翻譯。

目前資料為 12038 條有效 UI 詞條、1194 條 Web、143 條圖片規則及 149 張 PNG。

## 安裝與操作

完全關閉遊戲後，於更新包目錄執行：

    .\install.ps1 -GamePath 'C:\Users\SJ\Twinkle_StarKnightsX'

安裝器只更新 UI 擴充與資料，並清理前版撤下的 23 個已知替代 PNG。原 TSKHook.dll、共用 config.json、遊戲源檔、快取、自訂檔案及 workspace 連結保留。

- F9：重載詞表、圖片、規則與現有設定；DLL 更新需要重啟。
- F11：暫時切換漢化，不儲存設定。
- F4：採集目前介面的文字、字型及圖片資源。

本機已有來源專案連結時，會讀取 src/TSKHook.UI 的詞表；獨立安裝使用插件資料目錄中的詞表。

## 已知問題與限制

本輪 04:00「日期已更新」返回標題流程曾出現 `Exception: popup cache not found`，來源專案的 post-rollover-before-quantity-exit.log 第 79 行保留記錄。重新登入後可返回首頁，根因尚未唯一確定，目前未修復。

原 TSKHook 譯名下載曾因 SSL EOF 失敗並略過 UI 擴充；外部服務故障尚未永久修復，原劇情首次章節載入仍可能同步等待網路。歷史換日活動劇情的空參照尚未完成根因隔離。

鎖定、未取得內容及購買、抽取、實際養成等操作結果未全部實測，未來新增內容仍可能缺譯。Noto 繁體與日版 Rodin 字形不同；目前驗證不代表全遊戲與全部子頁已結案。

排查時請在重啟前保存 BepInEx/LogOutput.log 與 BepInEx/plugins/TSKHook.UI/unity-exceptions.log；後者每次啟動重置。BepInEx/ErrorLog.log 是另一份檔案，其空檔不能代替 UI 擴充例外捕獲的證據。
