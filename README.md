# TSKHook UI — 繁体中文 UI 汉化扩展

> 《Twinkle Star Knights》（闪耀星骑士，DMM Windows 版）的 BepInEx IL2CPP 界面汉化扩展。

**本扩展在上游 [TSKModding/TSKHook](https://github.com/TSKModding/TSKHook) (v1.1.6, GPL-2.0) 的基础上运行**，使用独立的 `TSKHook.UI.dll`，为菜单、角色与装备资料、任务、商店、抽卡详情等界面补充汉化，并修复已确认的切页与资源释放问题。感谢原作者与社区提供的框架、在线词典与灵感
注：此插件完全由GPT-6 Astra进行开发并上传无人工，有任何疑问请直接去问ai
---

## ✨ 主要功能

| 项目 | 原 TSKHook v1.1.6 | 安装本扩展后 |
|---|---|---|
| 剧情汉化 | 处理剧情正文及相关姓名 | 继续由原插件处理 |
| 游戏语言 | 繁体中文 | 保持繁体中文 |
| 界面文字 | 以原插件的剧情汉化范围为主 | 补充菜单、任务、角色、装备、商店及其他已收录界面 |
| 离线数据 | 使用原剧情词典 | 另外提供 **11,589 条 UI 词条、1,194 条网页词条** |
| 字体与图片 | 使用原插件字库 | 增加 UI 字库、**121 条图片规则及 127 张 PNG**，按原版字号与样式调整 |
| 未收录文字 | 保留原文 | 可选后台自动补译，成功结果写入本地缓存 |
| 原有文件 | 原插件及游戏文件 | 保留原剧情 DLL、字体、共用配置与已有缓存 |

### 保留原文的范围

以下内容按本版设定保留原文：

- 图鉴中的“装备图鉴”主入口。
- 出击中的“合同演习”“种族交流会”主入口。
- 星骑士中的“装备强化”主入口。
- 抽卡界面的卡池宣传底图，包括图片内嵌文案。
- 标题页及主页公告的正文、左侧文章标题、公告页签与文章子页。

**前三项仅保留主入口原图，其子界面继续汉化。主页“公告”按钮也继续汉化。** 游戏说明和抽卡详情网页仍使用繁体译文。

## 📦 安装与更新

> 本包是 UI 扩展包，需要先安装并正常运行 **TSKHook v1.1.6**。包内不含游戏本体、完整 BepInEx 运行环境或原剧情字库。

1. 如果尚未安装基础版，请先按照 [TSKHook 上游说明](https://github.com/TSKModding/TSKHook)完成安装，并确认原剧情汉化正常。
2. **完全关闭游戏**，解压 `TSKHook_UI_v0.1.0.zip` 发布包。
3. 将包内 TSKHook.UI.dll 和 TSKHook.UI 文件夹复制到游戏的 BepInEx/plugins/ 下，合并同名文件夹并替换本扩展的同名文件。
4. 重新启动游戏。在 `BepInEx/LogOutput.log` 中确认出现 `Loading [TSKHook UI 0.3.4]` 表示扩展已加载。

手动安装时仅复制 `BepInEx/plugins/TSKHook.UI.dll` 和 `BepInEx/plugins/TSKHook.UI/`。请保留原 `TSKHook.dll`、`config.json`、字体、缓存及已有的 `workspace.json` 词表链接。

完整操作说明见 **[使用说明.txt](使用说明.txt)**。

## ⚙️ 配置与可选自动补译

共用配置位于：

```text
游戏根目录/BepInEx/plugins/config.json
```

使用包内离线词表和人工图片，无需配置在线 API。需要为未收录文字自动补译时，可在现有配置的最外层添加或修改 `OnlineTranslation`。

下面仅展示可合并的配置片段，**不要用它替换整份文件**。原有 `speed`、`fps`、`translation`、`width`、`height`、`zoom` 及其他设置应保留。

```json
{
  "OnlineTranslation": {
    "Enabled": false,
    "url": "https://your-api.example/v1/responses",
    "ApiKey": "填写自己的 API 密钥",
    "Model": "填写服务支持的文字模型"
  }
}
```

- `Enabled`：`false` 关闭新请求；填好服务信息后可按需改为 `true`。
- `url`：填写支持 **Responses 接口**的服务地址，字段名使用小写 `url`。
- `ApiKey`、`Model`：填写自己的密钥和服务支持的模型名称。
- 保存后按 **F9** 生效。补译目标仍为繁体中文，已有离线译文优先使用。

图片自动补译由独立的 `ImageTranslation` 配置控制。人工 PNG 不依赖该服务；没有这个配置块也能使用包内图片。图片服务要求及配置示例见 TXT 说明。

## ⌨️ 快捷键

| 按键 | 功能 |
|---|---|
| **F9** | 重载词表、图片规则、PNG 和扩展配置，刷新当前界面 |
| **F4** | 采集当前已加载 UI 的原文、字体和图片信息，便于查漏 |
| **F11** | 临时开关汉化，关闭时恢复原文和原图，不保存开关状态 |
| **F1** | 由原 TSKHook 重读其基础配置 |

**更换 DLL 必须完全重启游戏；F9 只重载数据和配置。**

## 🛠 修改译文

1. 在当前生效的数据目录中找到对应的 `*-translations.json`。
2. 保留左侧日文原文键，只修改右侧繁体译文。
3. 保留数字、换行、富文本标签及 `{0}` 等占位符，并以 UTF-8 保存。
4. 回到游戏按 **F9**，重新打开相关界面检查。

独立安装使用 `BepInEx/plugins/TSKHook.UI/` 中的数据。若已有 `workspace.json` 链接到开发项目，则使用链接指向的项目词表；可通过启动日志中的 `UI dictionaries linked to project:` 确认。

## ❓ 常见问题与已知限制

**为什么部分入口和公告还是日文？**  
这些内容属于上方列出的保留原文范围；入口的子界面按说明继续汉化。

**修改词表后没有变化？**  
先确认修改的是当前生效的数据目录，再按 F9。更新 DLL 后请完全重启游戏。

**自动补译返回 HTTP 429 或没有译文？**  
服务可能限流或额度不足。插件会暂停重试并保留原文，已有离线词表和缓存仍可使用。请同时检查服务是否支持 Responses 接口及所填模型。

**还能保证所有场景都没有问题吗？**  
本版验证覆盖当前可进入的既有汉化页型。期间锁定、特定角色与培养状态、未触发的战斗状态，以及部分付费、抽取、消耗材料或保存后的结果，尚未全部实机验证。

其他已知限制：

- 礼物历史错图已通过代码测试，但原记录已超出可查看日期，同一笔记录的修复后实机结果尚未取得。
- 少数新增敌人名采用暂定音译，尚未取得中文 Wiki 的固定译名。
- 繁体字形使用现有 Noto 字库，以原版字号、粗细、斜体、描边和布局为基准；图片内嵌字的确切字体家族尚未全部确认。
- 原剧情插件首次下载未缓存章节时的同步等待行为保持原样。

遇到异常时请保留以下两份日志，并记录触发界面和操作顺序：

```text
BepInEx/LogOutput.log
BepInEx/plugins/TSKHook.UI/unity-exceptions.log
```

日志可能在重启时覆盖；不能只凭第二个文件为空判断没有错误。
